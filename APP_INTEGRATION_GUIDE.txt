APP-WIDE P2P INTEGRATION GUIDE
===============================

All pages in UtilityPro now use P2P SQLite with automatic sync across devices.


FILE STRUCTURE & LOAD ORDER
============================

Every HTML file should have this order in <head> or before </body>:

1. Sidebar (always first)
   <script src="sidebar.js"></script>

2. Configuration (before anything else)
   <script src="config.js"></script>

3. P2P Client
   <script src="p2p-client.js"></script>

4. Database API
   <script src="db-api.js"></script>

5. Your page script
   <script>
       // Your code here
   </script>


EXAMPLE STRUCTURE
=================

<!DOCTYPE html>
<html>
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My Page</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <div id="sidebar-container"></div>
    
    <main class="main-content">
        <!-- Your content here -->
    </main>

    <!-- Scripts in order -->
    <script src="sidebar.js"></script>
    <script src="config.js"></script>
    <script src="p2p-client.js"></script>
    <script src="db-api.js"></script>
    
    <script>
        // Initialize
        let db = null;
        let p2pClient = new P2PClient();
        
        window.addEventListener('load', async () => {
            // Connect to P2P server
            const result = await p2pClient.connectToHost(SERVER_URL);
            if (result.success) {
                console.log('✓ Connected to P2P');
                p2pClient.startAutoSync(5000);
                
                // Initialize database API with P2P
                db = new DatabaseAPI(SERVER_URL, p2pClient);
                
                // Load data
                await loadData();
            } else {
                alert('Could not connect to P2P server');
            }
        });
        
        async function loadData() {
            const result = await db.getAllCustomers();
            if (result.success) {
                console.log('Customers:', result.customers);
                // Display data...
            }
        }
        
        // Theme toggle
        function toggleTheme() {
            document.body.classList.toggle('dark-mode');
            localStorage.setItem('theme', document.body.classList.contains('dark-mode') ? 'dark' : 'light');
        }
        
        // Apply saved theme
        if(localStorage.getItem('theme') === 'dark') {
            document.body.classList.add('dark-mode');
        }
    </script>
</body>
</html>

FORMS & VALIDATION
==================

// Form submission
document.getElementById('form').addEventListener('submit', async (e) => {
    e.preventDefault();
    
    // Get form data
    const formData = new FormData(e.target);
    const data = Object.fromEntries(formData);
    
    // Validate
    if (!DatabaseAPI.isValidPhone(data.phone)) {
        alert('Invalid phone number');
        return;
    }
    
    if (!DatabaseAPI.isValidEmail(data.email)) {
        alert('Invalid email');
        return;
    }
    
    // Save
    const result = await db.saveCustomer(data);
    
    if (result.success) {
        alert('✓ Saved!');
        e.target.reset();
        // Reload data
        await loadData();
    } else {
        alert('✗ Error: ' + result.error);
    }
});

PERFORMANCE TIPS
================

1. Batch updates when possible
2. Use debouncing for search
3. Cache frequently accessed data
4. Limit initial data load
5. Use pagination for large datasets
6. Minimize sync frequency for slow networks


TROUBLESHOOTING
===============

Q: "SERVER_URL not defined"
A: Make sure config.js is loaded before your script

Q: "DatabaseAPI not defined"
A: Load db-api.js before your script

Q: "Changes not syncing"
A: Check if p2pClient is connected: p2pClient.isHostConnected()

Q: "Promise rejected" errors
A: Check if server is running: npm start

Q: "CORS errors"
A: CORS is enabled in server. Check firewall allows port 3000
