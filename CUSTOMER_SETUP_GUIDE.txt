📋 CUSTOMER INFORMATION SYSTEM - SETUP GUIDE

This guide will help you set up the complete customer information management system.

═══════════════════════════════════════════════════════════════════════

STEP 1: CREATE GOOGLE SHEETS DATABASE
═══════════════════════════════════════════════════════════════════════

1. Open Google Drive (drive.google.com)
2. Click "New" → "Google Sheets" → "Blank Spreadsheet"
3. Name it "UtilityPro Customer Database"
4. Create 3 sheets by right-clicking sheet tabs:
   - Sheet 1: Rename to "Customers" (data will auto-populate)
   - Sheet 2: Rename to "Activity Log" (logs of all actions)
   - Sheet 3: Rename to "Service Requests" (tracked service requests)
5. DELETE the default "Sheet1" if it's still there

📍 IMPORTANT: Copy the Sheet ID from the URL
   Example URL: https://docs.google.com/spreadsheets/d/1A2B3C4D5E6F7G8H9I0J/edit
   The ID is: 1A2B3C4D5E6F7G8H9I0J
   
   Keep this ID safe, you'll need it later! ✓

═══════════════════════════════════════════════════════════════════════

STEP 2: CREATE GOOGLE APPS SCRIPT
═══════════════════════════════════════════════════════════════════════

1. Open the Google Sheet you created above
2. Click "Extensions" → "Apps Script"
3. In the new tab, you'll see the editor
4. Delete all existing code (usually shows "function myFunction() {}")
5. Copy the ENTIRE contents from the file: appscript-code.gs
6. Paste it into the Apps Script editor
7. At the TOP of the code, update these values:

   Line ~13: const SHEET_ID = 'YOUR_GOOGLE_SHEET_ID';
   Replace with your ID from Step 1 ↑
   
   Line ~17: const DRIVE_FOLDER_ID = 'YOUR_DRIVE_FOLDER_ID';
   (Optional - for photo uploads. Create a folder and get its ID from URL)

8. Click "Save" (or Ctrl+S)
9. You should see "appsscript.json" appear on the left

═══════════════════════════════════════════════════════════════════════

STEP 3: DEPLOY AS WEB APP
═══════════════════════════════════════════════════════════════════════

1. In Apps Script editor, click "Deploy" → "+ New deployment"
2. Click the gear icon → Select "Web app"
3. Fill the form:
   - Description: "Customer Form Handler" (optional)
   - Execute as: [Your Google Account Email]
   - Who has access: "Anyone"
4. Click "Deploy"
5. A popup will appear asking for permissions - click "Authorize"
6. Review the Google account
7. Click "Advanced" → "Go to Customer Form Handler (unsafe)"
8. Allow permissions
9. You'll see a "Deployment successful" message ✓

📍 IMPORTANT: Copy the Web App URL
   It looks like: https://script.google.com/macros/d/ABC123XYZ.../userlp?v=1
   Keep this safe! ✓

═══════════════════════════════════════════════════════════════════════

STEP 4: CONNECT TO YOUR APP
═══════════════════════════════════════════════════════════════════════

1. Open the file: customer-info-form.html
2. Find this line (around line 240):
   const APPS_SCRIPT_URL = 'https://script.google.com/macros/d/YOUR_SCRIPT_ID/userlp?v=1';

3. Replace the URL with your Web App URL from Step 3
4. Save the file

Example (before):
const APPS_SCRIPT_URL = 'https://script.google.com/macros/d/YOUR_SCRIPT_ID/userlp?v=1';

Example (after):
const APPS_SCRIPT_URL = 'https://script.google.com/macros/d/AKfycbw3_xY2Z9A1B2C3D4E5F6G7H8I9/userlp?v=1';

═══════════════════════════════════════════════════════════════════════

STEP 5: TEST THE SYSTEM
═══════════════════════════════════════════════════════════════════════

1. Open your UtilityPro app
2. Go to "📋 Customer Information Form" from sidebar (or search)
3. Fill in some test data:
   - First Name: "Test"
   - Last Name: "Customer"
   - Email: "test@example.com"
   - Phone: "9876543210"
   - City: "Patna"
   - State: "Bihar"
   - PIN Code: "800001"
   - Check some service preferences
4. Click "💾 Save Customer Information"

✓ If you see "✅ Customer information saved successfully!" 
   → Setup is complete! All data is being saved to Google Sheets

✗ If you see an error:
   → Check that APPS_SCRIPT_URL is correct
   → Verify SHEET_ID is in the Apps Script code
   → Check the Google Apps Script deployment is active

ADVANCED FEATURES (OPTIONAL)
═══════════════════════════════════════════════════════════════════════

The appscript-code.gs file includes these functions you can use:

1. getCustomerByPhone("9876543210")
   → Retrieve customer data by phone number

2. getCustomerById("CUST-1234567890")
   → Retrieve customer by unique ID

3. getAllCustomers(100)
   → Get last 100 customers

4. searchCustomers("Rajesh")
   → Search by name, email, phone, or aadhar

5. updateCustomer("CUST-1234567890", {status: "Inactive"})
   → Update specific customer fields

6. deleteCustomer("CUST-1234567890")
   → Delete a customer record

7. getCustomerStats()
   → Get statistics (total customers, active count, top services)

These functions are available in the Apps Script console for advanced usage.

TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════

Problem: "Error saving customer information"
Solution: 
- Check APPS_SCRIPT_URL is correct in customer-info-form.html
- Verify the Apps Script deployment is "Active"
- Check browser console (F12) for error details

Problem: Data not appearing in Google Sheets
Solution:
- Verify SHEET_ID is correct in appscript-code.gs
- Check that sheet names are exactly: "Customers", "Activity Log", "Service Requests"
- Try adding spaces: "Customers " (sometimes sheet names have trailing spaces)
- Check the Activity Log sheet for errors

Problem: Form submission times out
Solution:
- Make sure your internet connection is stable
- Check if Google Sheets quota is reached (usually not an issue)
- Try clearing browser cache and cookies

Problem: Authorization failed
Solution:
- Re-deploy the Apps Script as Web App
- Make sure "Who has access" is set to "Anyone"
- Check that you authorized all requested permissions

SECURITY NOTES
═══════════════════════════════════════════════════════════════════════

⚠️ IMPORTANT: Customer data is sensitive!

1. The form submission is HTTPS encrypted
2. Google Sheets has built-in access controls
3. Set Google Sheet visibility to your organizational domain only
4. Make regular backups of your customer data
5. Don't share the Apps Script deployment URL publicly
6. Consider enabling 2-Factor Authentication on your Google account
7. Review Activity Log regularly for suspicious activity
