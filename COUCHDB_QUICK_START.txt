🚀 COUCHDB MIGRATION - QUICK START GUIDE
==========================================

Your UtilityPro is now switching from SQLite to CouchDB for TRUE distributed synchronization!

WHAT CHANGED:
=============
❌ OLD: SQLite (single database file) → P2P direct connection
✅ NEW: CouchDB (distributed database) → Real-time replication between all devices

KEY BENEFITS:
=============
✓ NO single point of failure (no "host down = clients blocked")
✓ Every device gets full replica
✓ Automatic sync between all devices
✓ Works offline, syncs when online
✓ Conflict resolution built-in
✓ True peer-to-peer data management


⚙️ INSTALLATION STEPS
====================

STEP 1: Install CouchDB (Windows)
---------------------------------
1. Download from: https://couchdb.apache.org/
2. Run the installer
3. ✓ Check "Install as Service" during installation
4. During setup, create Admin user with password (remember it!)
5. CouchDB will run on the default port 5984

STEP 2: Install Node.js Dependencies
-------------------------------------
Open PowerShell/Command Prompt in your UtilityPro folder:

    cd C:\Users\myraj\OneDrive\Desktop\UtilityPro
    npm install

This will install PouchDB and other new dependencies.



🔧 RUNNING THE SYSTEM
====================

THREE-STEP STARTUP:

1️⃣  START COUCHDB:
    Option A (Easy): Double-click ➜ couchdb-start.bat
    Option B (Manual): Open cmd and type: couchdb
    
    ✓ You should see: [info] Apache CouchDB... started
    ✓ Or visit: http://localhost:5984/%5F/utils/

2️⃣  START NODE SERVER:
    Open PowerShell/Command Prompt:
    
    cd C:\Users\myraj\OneDrive\Desktop\UtilityPro
    npm start
    
    ✓ You should see:
       ✓ Server running on: http://192.168.x.x:3000
       ✓ CouchDB connected: http://localhost:5984

    - Local device: http://localhost:3000

📱 CONNECTING OTHER DEVICES
============================

Device A (MAIN):
1. Start CouchDB: couchdb-start.bat
2. Start Server: npm start
3. Note the HTTP address shown (e.g., http://192.168.1.50:3000)

Device B (CLIENT):
1. Open browser
2. Go to: http://192.168.1.50:3000
3. All data from Device A is now replicated!
4. Both devices sync AUTOMATICALLY
5. Device A can now go offline, Device B still has all data

Device C, D, E... (Multiple Devices):
- Repeat same process
- ALL devices sync together automatically!


🎯 HOW IT WORKS NOW
====================

BEFORE (SQLite):
┌─ Device A (HOST) ─┐        ┌─ Device B ─┐        ┌─ Device C ─┐
│  SQLite Database │  ◄────► │  P2P Link  │        │ P2P Link   │
│  (single file)   │         │  (blocked  │        │ (blocked   │
└──────────────────┘         │  if A down)│        │ if A down) │
                             └────────────┘        └────────────┘

AFTER (CouchDB):
┌─ Device A ─┐        ┌─ Device B ─┐        ┌─ Device C ─┐
│ CouchDB    │  ◄────►│ CouchDB    │  ◄────►│ CouchDB    │
│ Full Copy  │        │ Full Copy  │        │ Full Copy  │
└────────────┘        └────────────┘        └────────────┘
     ✓ Works offline    ✓ Works offline    ✓ Works offline
     ✓ Always syncs      ✓ Always syncs      ✓ Always syncs

🆘 TROUBLESHOOTING
==================

Problem: "CouchDB not found" on startup
Solution:
  - Install CouchDB from: https://couchdb.apache.org/
  - Make sure you selected "Install as Service"
  - Restart computer after installation

Problem: "Connection refused" error
Solution:
  - Verify CouchDB is running (couchdb-start.bat or check background)
  - Verify port 5984 is not blocked
  - Check Windows Firewall doesn't block couchdb

Problem: Devices not syncing
Solution:
  - Verify all devices are on same network
  - Verify server.js is running on the main device
  - Check no firewall is blocking port 3000
  - Refresh the browser on client devices

Problem: "Cannot connect to database"
Solution:
  - Make sure you ran: npm install (don't skip this!)
  - Don't delete customers.db file if it exists
  - Delete node_modules and run: npm install again
