KEY FEATURES
============

✅ No Internet Required
   - Works entirely on local WiFi
   - No cloud dependency
   - Data stays on your network

✅ Real-time Sync
   - Add customer on Device 1
   - Automatically appears on Device 2, 3, 4...
   - Auto-sync every 5 seconds (configurable)

✅ Offline Support
   - Each device has local copy
   - Works offline if disconnected
   - Re-sync when back on network

✅ Direct Device Discovery
   - Scans WiFi network for host
   - Auto-detects active servers
   - Manual IP input also supported

✅ Activity Logging
   - All operations tracked
   - Sync history available
   - Debug info in logs


HOW TO USE IN YOUR APP
======================

Add to your HTML file:

<head>
    <script src="p2p-client.js"></script>
</head>

<script>
    // Create P2P client
    const p2p = new P2PClient();
    
    // Discover hosts on network
    const hosts = await p2p.discoverHosts('192.168.1');
    
    // Connect to first host
    await p2p.connectToHost(hosts[0].url);
    
    // Auto-sync every 5 seconds
    p2p.startAutoSync(5000);
    
    // Sync immediately
    await p2p.syncDatabase();
    
    // Send changes to host
    await p2p.pushChanges([{
        action: 'INSERT',
        table: 'customers',
        data: customerData
    }]);
</script>

TROUBLESHOOTING
===============

"Server won't start"
→ npm install
→ Check Node.js is installed: node --version
→ Port 3000 in use? Change PORT in server.js

"Can't find host"
→ Make sure host is running (npm start)
→ Verify all devices on same WiFi
→ Try manual IP connection
→ Check firewall allows port 3000

"Sync not working"
→ Check connection status in browser
→ Look at server terminal for errors
→ Try manual sync with "Sync Now" button
→ Restart server: Ctrl+C, then npm start

"Database locked"
→ Stop all instances
→ Delete customers.db  (backup first!)
→ Restart server

"Changes not syncing"
→ Check auto-sync is active
→ Increase sync frequency (reduce interval)
→ Check network is stable
→ Verify host device hasn't gone to sleep


IMPORTANT TIPS
==============

1. Host Device
   - Keep plugged in (don't sleep)
   - Don't close terminal
   - Check firewall settings
   - Use strong WiFi signal

2. Client Devices
   - Stay within WiFi range
   - Don't force-close browser
   - Check connection in dev tools
   - Use modern browser (Chrome 90+, Safari 14+)

3. Network
   - Use 2.4GHz WiFi for better range
   - Reduce interference (away from microwaves)
   - Check WiFi password is correct
   - Verify all devices see same network

4. Database
   - Backup customers.db regularly
   - Avoid simultaneous edits (latest wins)
   - Check disk space on host device
