TROUBLESHOOTING
===============

Q: "Cannot connect to server"
A: 1. Check if npm start is running
   2. Verify IP is 192.168.1.105 (or your actual IP)
   3. Check if devices are on same WiFi
   4. Firewall might block port 3000

Q: "Data not syncing across devices"
A: 1. Check P2P status on p2p-test.html
   2. Verify both devices connected to same WiFi
   3. Refresh the page (F5)
   4. Check browser console (F12) for errors

Q: "Server won't start"
A: 1. Check Node.js installed: $ node --version
   2. Check SQLite installed: $ npm list sqlite3
   3. Delete node_modules, run $ npm install
   4. Try Command Prompt instead of PowerShell

Q: "Port 3000 already in use"
A: 1. Kill the existing process
   2. Or change PORT in server.js to 3001
